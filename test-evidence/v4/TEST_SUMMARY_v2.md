## The Scan Chain Fix

### Problem
```
ERROR: Scan chains exist in this design but are not defined for 99.95% flops
```

### Root Cause
Synthesis stage (dc_shell) inserted DFT scan chains via `insert_dft`, but the Placement stage in Innovus didn't load the scan chain definition file.

### Solution
Added to `skills/ibex-rtl2gds-flow.md` Stage 4 (Placement):

```tcl
source /home/EDA/ibex_work_upload/result/pr/data/powerplan.enc

# Load scan chain definition (required after DFT insertion in synthesis)
# The scan DEF was generated by write_scan_def in Stage 0
loadDef -scan result/scanchain/data/ibex_core.scan.def

# Timing derate...
```

### Result
✅ Placement completed successfully, flow continued through all remaining stages.
